# CodeAlpha Basic Network Sniffer

A basic network sniffer built with Python and Scapy.

## Project Description

This project captures a limited number of network packets
and analyzes basic packet information.

The program displays:

- Source IP address
- Destination IP address
- Protocol
- Source port
- Destination port
- Packet length
- Payload length

The project was created as part of the CodeAlpha Cyber Security Internship.

## Technologios used
-python
-scapy
Npcap(windows packet)
